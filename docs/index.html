Features

必要な数字だけ、いつもの場所に。

01

メニューバー

最も逼迫している枠を常時表示。クリックすると全サービスの使用状況を確認できます。

02

デスクトップウィジェット

小・中サイズに対応。表示対象を選び、デスクトップから残量を確認できます。

03

リセット時刻

使用率だけでなく、次のリセットまでの時間とデータの鮮度も表示します。

Privacy by design

何を読み、どこへ通信するかを明確に。

利用状況の取得に必要な範囲だけを扱います。OAuthトークンやローカルログの内容を AI Usageの設定・スナップショット・通常ログへ保存しません。

Codex / Grok

Mac内に各ツールが保存した利用状況ログを読みます。API通信やトークン消費はありません。

Claude Code

macOS KeychainのClaude Code認証情報を使い、使用率取得時だけAnthropicのusage APIへ通信します。

アプリ本体 / Widget

本体が収集し、必要最小限の表示用スナップショットだけをApp Group経由でWidgetへ渡します。

ローカルアクセス

本体は各ツールのログを読むため非サンドボックスです。ログ末尾をメモリ上で解析し、会話本文や元の行を保存・送信しません。

AI Usageは独立した非公式アプリです。OpenAI、Anthropic、xAI、Appleによる提供・承認・提携を示すものではありません。 表示値は参考情報で、請求・契約上の正式な残量は各サービスの公式画面で確認してください。 Appleの公証は機能・プライバシー審査や推奨を意味しません。

Install

5ステップで使い始められます。

macOS 14 Sonoma以降。初回はDMGを手動導入し、それ以降はアプリ内で更新を確認できます。

  1. 1
    入手してインストール

    公式ページでSHA-256を確認し、DMG内のAI UsageをApplicationsへドラッグします。

  2. 2
    対応ツールを準備

    Claude Codeへログインします。CodexとGrokは一度通常の応答を完了してログを作ります。

  3. 3
    AI Usageを起動

    使用量は自動で確認されます。macOSから求められた場合だけ、公証済み配布版か確認してClaude CodeのKeychainアクセスを許可します。

  4. 4
    言語と表示を選ぶ

    設定で日本語・Englishとエージェントの表示／非表示を選び、一覧でカードの順序を整えます。

  5. 5
    ウィジェットを追加

    macOSの「ウィジェットを編集」からAI Usageを追加します。値の更新には本体を起動しておきます。
